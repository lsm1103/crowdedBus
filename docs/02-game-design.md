# 游戏设计文档（GDD）

## 1. 对局总览

一局由“候车上车—车厢求生—终点决战—结算”组成，目标是在终点前不被挤出车门或甩出安全区。标准局 8 人、约 180 秒；人数不足时加入 AI 路人维持拥挤感。

```text
房间 / 匹配 → 候车（15 秒）→ 上车（20 秒）→ 行驶与停站（约 120 秒）
→ 终点摇摆（30 秒）→ 冠军结算 → 再来一局 / 分享
```

## 2. 胜负规则

- 玩家生命状态为“在车内”“危险边缘”“返场等待”“淘汰”。
- 被推出车门区域、在车体甩动中离开边界，或未能在倒计时内完成上车，即触发出局判定；处于开局返场保护时转为“返场等待”，否则淘汰。
- 终点决战结束时，仍在车内且排名最高的玩家获胜；若多人同时存活，按安全值（距危险区、扶手状态）判定，仍相同则共同获胜并在结算中说明。
- 被淘汰者立即进入观战，可使用不影响胜负的表情；首版不允许淘汰者干扰场内。

为避免好友在开局几十秒就只能观战，前 60 秒启用一次“下一站返场”保护：首次掉出车外会在下一站从后门返回，并失去 20% 技能充能；保护期结束或第二次掉出才正式淘汰。该规则需要通过试玩验证，若削弱了紧张感，可改为仅对首次参与的新玩家生效。

## 3. 玩家操作

| 输入 | 行为 | 设计目的 |
| --- | --- | --- |
| 左虚拟摇杆 | 8 方向移动 | 基础走位与抢位 |
| 冲刺按钮 | 向当前方向短冲，冷却 3 秒 | 制造进攻与逃离时机 |
| 推挤按钮 | 向朝向进行短距离推挤，冷却 2 秒 | 主要互动手段 |
| 交互按钮 | 靠近扶手时抓住或松开 | 对抗急刹与摇摆 |
| 表情按钮 | 发送快捷表情 | 增加社交反馈 |

操作约束：冲刺和推挤不应穿过角色或墙体；被推玩家有极短硬直，但仍能操控；连续受击必须有递减击退或短暂无敌，防止多人无限连控。

## 4. 核心数值初稿

这些数值仅用于原型测试，实际以可玩性为准。

| 参数 | 初稿 | 说明 |
| --- | ---: | --- |
| 步行速度 | 1.0 | 基准速度 |
| 冲刺距离 | 2.5 格 | 不可穿墙，可被扶手阻挡 |
| 推挤距离 | 1.2 格 | 根据目标质量和抓扶手状态修正 |
| 扶手减伤 | 70% | 仍可能因极端事件脱手 |
| 受击保护 | 0.7 秒 | 降低连续推挤强度 |
| 拥挤度起点 | 45 / 100 | 随停站和事件上升 |
| 高压阈值 | 80 / 100 | 启用更强事件与视觉告警 |

## 5. 地图与空间规则

车厢由候车区、前门、过道、座位区、扶手区和后门组成。座位区不是绝对安全：坐下或贴近座位会降低位移，但转向和离开需要更长时间。前后门是高风险区域，停站开门期间边界更危险。

设计原则：任何淘汰必须让玩家看见其原因。危险区用黄色地面线和闪烁门灯表示；急刹前有司机提示、刹车声和短预警；推挤命中要显示方向、力度和受击反馈。

## 6. 阶段规则

### 候车与上车

玩家在站台出生。开门后需穿过门口进入车厢；倒计时结束未进车者淘汰。此阶段只启用移动和冲刺，避免开局因推挤造成无法理解的失败。

### 行驶与停站

大巴每 25～35 秒到站一次。每站提高拥挤度并生成少量 AI 路人；系统从事件池选择一项事件。玩家可推挤、抢扶手、调整位置。

### 终点摇摆

剩余玩家进入 30 秒高压阶段，车体左右摇摆、车门区域扩大。停止摇摆后结算。此阶段不再生成大量 AI，以保证读图和性能。

## 7. 随机事件池（首版）

| 事件 | 预告 | 实际效果 | 反制 |
| --- | --- | --- | --- |
| 急刹车 | 1 秒刹车灯、司机语音 | 全体朝车头滑动 | 抓扶手、远离前门 |
| 急转弯 | 方向箭头 | 全体向车侧滑动 | 提前换边、抓扶手 |
| 下一站上人 | 停站广播 | 增加 AI 路人，拥挤度 +15 | 提前占据过道边缘 |
| 大件行李 | 行李提示 | 生成可推动障碍 | 绕行或利用其挡人 |
| 车门故障 | 门灯闪烁 | 一扇门危险区扩大数秒 | 转移至另一侧 |

事件选择需要避免连续出现同一种强控制，且第一局前两次事件优先使用容易理解的急刹与上人。

## 8. 结算与奖励

结算展示冠军、淘汰顺序、三个“本局时刻”（如最远冲刺、扶手救命、推挤次数），并提供再来一局、邀请好友与返回大厅。首版只使用非付费的经验/软币占位奖励，奖励不影响对局强度。

## 9. 新手引导

首次进入时采用“边玩边提示”：候车阶段提示移动和冲刺；第一次急刹前提示抓扶手；第一次靠近门口提示危险线。每条提示只出现一次、可跳过，禁止长篇弹窗教程。
