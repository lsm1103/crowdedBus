## 文档原则

- `MVP`（最小可行产品）优先：先证明“和朋友一起挤公交是否好玩”。
- 规则优先于内容量：先完成一个有趣且稳定的角色、地图和对局循环，再增加角色与皮肤。
- 所有数值均为初稿，必须通过试玩调整；它们不是最终承诺。
- 暂不将付费、排行榜、赛季或大量社交系统作为首个可玩版本的前置条件。

## 当前范围

首个可玩版本目标为：2～8 名玩家在一张斜 45° 2.5D 公交车地图中完成一局约 3 分钟的实时对抗，包含移动、物理推挤、角色技能、扶手、3 类随机事件、淘汰与结算。好友房和微信邀请属于首发功能；开发阶段允许用本地机器人或局域测试逐步替代真人联调。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 对局 | 从进入房间到结算的一次完整游戏 |
| 回合 | 对局内围绕某一站或某一事件展开的短阶段 |
| 安全区 | 不会因车门、甩动而直接淘汰的车厢区域 |
| 拥挤度 | 表示车厢压力并驱动事件升级的数值 |
| AI 路人 | 非玩家控制的普通乘客，用来制造拥挤和障碍 |
| MVP | 用最少内容验证核心乐趣的首个版本 |
