# 产品概述

## 1. 一句话定义

《好挤的大巴》是一款面向微信好友的实时派对小游戏：玩家在不断上人的摇晃大巴中抢位置、抓扶手、推挤对手，并坚持到终点。

## 2. 目标与非目标

### 产品目标

- 让 2～8 名熟人能在 3 分钟内获得可复述、可分享的搞笑对局瞬间。
- 让首次进入的玩家不读教程也能完成移动、冲刺和推挤。
- 在中低端手机上保持清晰的同屏信息和稳定帧率。

### 首版非目标

- 不做开放世界、剧情战役、复杂养成或数十名平衡差异很大的英雄。
- 不以付费数值或强制广告推动首轮留存。
- 不承诺一开始就支持跨区大规模实时匹配；先验证小房间联机质量。

## 3. 目标用户与使用场景

| 用户 | 需求 | 对应设计 |
| --- | --- | --- |
| 微信群好友 | 快速一起玩、互相调侃 | 一键邀请、开房、短局、结算表情 |
| 独自上线的轻度玩家 | 随时开始、不怕等人 | 快速匹配或机器人补位 |
| 新手开发团队 | 控制开发风险 | 单地图、统一角色基础能力、事件驱动复玩 |

典型场景：群里有人发出挑战卡片，好友点击进入房间，在等待期间可移动和发表情；房主开始后全员进入同一辆车，结束后可直接“再挤一局”。

## 4. 核心体验支柱

1. **空间很挤**：位置本身就是资源；站位、座位、扶手和车门都重要。
2. **动作很傻但结果清楚**：每次推挤、急刹、抓住扶手都要有明确反馈。
3. **熟人互坑但不过度挫败**：被淘汰后仍可观战、发弹幕或影响轻微事件。
4. **每局有变化**：事件顺序、AI 路人和最终安全位置组合不同。

## 5. 竞争模式与房间规则

| 模式 | 人数 | 用途 | 首版优先级 |
| --- | ---: | --- | --- |
| 好友房 | 2～8 人 | 微信邀请、群友开黑 | P0 |
| 快速匹配 | 8 人目标，可机器人补位 | 单人进入 | P1 |
| 双人合作 | 2 人 | 后续玩法扩展 | P2 |

好友房允许房主在人数不少于 2 人时开始。少于 8 人的空位由 AI 路人填补，不把机器人伪装成真人。断线玩家优先短暂重连，超时后转为静止路人，避免其角色成为可被滥用的目标。

## 6. 首版成功标准

首轮封闭试玩应观察以下问题，而不是过早追逐流水数据：

| 指标或观察 | 初始判定标准 |
| --- | --- |
| 完成率 | 大多数测试者能完成一局且愿意再来一局 |
| 规则理解 | 试玩后能准确说出“抓扶手”和“别站门口”的用途 |
| 高光时刻 | 每局至少出现一次多人能看懂的反转或笑点 |
| 技术稳定性 | 8 人测试下无持续不同步、无阻断性崩溃 |
| 公平感 | 输家大多能指出可改进的操作或站位，而非认为结果随机 |

## 7. 版本边界

首版使用一个可换主题的“早高峰公交车”场景，采用斜 45° 2.5D 视角。8 名首发角色各有一个主动技能，但共享相同的移动、碰撞体和基础推挤数值，避免角色差异破坏底层平衡。好友房与微信邀请是首发闭环的一部分；皮肤、段位、广告和付费仍在核心玩法稳定后单独立项。
